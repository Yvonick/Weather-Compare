Data reference

Official documentation for the APIs and thresholds used on this page.

  • Open-Meteo Forecast API — upcoming weather variables and precipitation probability
  • Open-Meteo Historical Weather API — archived weather variables
  • Open-Meteo Air Quality API — air-quality indicators and UV index
  • Open-Meteo Geocoding API — place lookup and source labels
  • UK Met Office — rolling seven-day archive of one-minute land observations
  • DMI Denmark — hourly extrema and ten-minute observations
  • MET Norway Frost — official hourly aggregates (client ID required)
  • DWD Germany — ten-minute temperatures and extrema
  • Météo-France — quality-controlled hourly temperature extrema via data.gouv.fr (OAuth application used for station discovery)
  • MeteoSwiss — ten-minute automatic-station observations
  • KNMI Netherlands — ten-minute station observations (API key required)
  • GeoSphere Austria — official ten-minute extrema
  • FMI Finland — ten-minute station observations
  • IEM / NOAA ASOS — U.S. five-minute airport observations, with routine and special reports as fallback
  • EEA European AQI methodology — air-quality guide bands
  • GeoNames — underlying place dataset attribution
